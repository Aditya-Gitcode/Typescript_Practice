# Typescript_Practice
Here are some ts codes on Variables and Data Types, Functions, Abstract class, Interface, Classes and Object, Generics

# Steps to install TypeScript
- TypeScript works using Node.js
- Go to the official website
- Download LTS version
- Install it normally.
- After installing, check in terminal: node -v
- Then check npm -v
- Open terminal or the terminal inside Visual Studio Code and run
- npm install -g typescript
- -g means global installation (usable everywhere)

# Steps to compile TypeScript files
- Install Node.js
- Install TypeScript using npm install -g typescript.
- Create a .ts file (example: app.ts).
- Open terminal in Visual Studio Code.
- Compile using tsc app.ts.
- A .js file (example: filename.js) will be generated.
- Run the file using node filename.js.

# Steps to run the generated JavaScript file
- Install Node.js.
- Open terminal in Visual Studio Code.
- Navigate to the folder containing the .js file.
- Type node filename.js.
- Press Enter to execute the JavaScript file.
